## 3. Giới thiệu đề tài

PH Store là hệ thống website hỗ trợ kinh doanh điện
thoại iPhone trực tuyến, giúp khách hàng dễ dàng tìm
kiếm, xem thông tin, đánh giá và lựa chọn sản phẩm.

Hệ thống cung cấp trang quản trị riêng để người quản
trị quản lý sản phẩm, khách hàng và hoạt động kinh doanh.

## 4. Mục tiêu đề tài

- Xây dựng website bán điện thoại hoàn chỉnh.
- Hỗ trợ đăng ký, đăng nhập và phân quyền.
- Quản lý sản phẩm, giỏ hàng và đánh giá.
- Hỗ trợ mua hàng qua điện thoại, SMS, Zalo, Facebook.
- Xây dựng trang quản trị Admin riêng.
- Đảm bảo an toàn và bảo mật hệ thống.
- Triển khai website phục vụ kinh doanh thực tế.

## 5. Công nghệ dự kiến

| Thành phần | Công nghệ |
|---|---|
| Frontend | ReactJS, Tailwind CSS |
| Backend | Python, Django REST Framework |
| Database | PostgreSQL |
| Server | Ubuntu Server |
| Web Server | Nginx |
| Deployment | Docker |
| Version Control | Git, GitHub |
