# TÌM HIỂU NGÔN NGỮ MARKDOWN

## 1. Markdown là gì?

Markdown là ngôn ngữ đánh dấu nhẹ, sử dụng cú pháp
đơn giản để định dạng văn bản.

Markdown thường được sử dụng để viết tài liệu phần mềm,
README, báo cáo tiến độ và hướng dẫn sử dụng trên GitHub.

## 2. Các cú pháp cơ bản

### Tiêu đề cấp 3

- `Đoạn mã ngắn`

## 3. Ưu điểm của Markdown

- Cú pháp đơn giản, dễ học.
- Dễ dàng chỉnh sửa và quản lý tài liệu.
- Hỗ trợ hiển thị trực tiếp trên GitHub.
- Hỗ trợ trình bày mã nguồn.
- Thuận tiện theo dõi lịch sử thay đổi thông qua Git.

## 4. Ứng dụng Markdown trong đồ án PH Store

- Viết tài liệu giới thiệu dự án README.md.
- Viết báo cáo tiến độ hằng ngày.
- Trình bày tài liệu phân tích nghiệp vụ.
- Mô tả yêu cầu chức năng và phi chức năng.
- Viết tài liệu thiết kế hệ thống.
- Viết tài liệu hướng dẫn cài đặt và triển khai.
- Ghi chú lỗi và kết quả kiểm thử.
